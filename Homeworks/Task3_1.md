# 📦 Задание 1. Умный калькулятор стоимости доставки

Интернет-магазину необходимо автоматически рассчитывать стоимость доставки заказа.

### Входные данные

Пользователь вводит:

* стоимость заказа;
* расстояние доставки в километрах;
* является ли он постоянным клиентом (`да` / `нет`).

### Правила расчёта

1. Базовая стоимость доставки — **300 руб.**
2. Если расстояние больше **10 км**, за каждый километр сверх 10 км добавляется **30 руб.**
3. Если стоимость заказа составляет **5000 руб. или больше** и расстояние не превышает **10 км**, доставка бесплатная.
4. Если покупатель является постоянным клиентом и стоимость заказа составляет **3000 руб. или больше**, предоставляется скидка **50% на доставку**.

Программа должна вывести:

* стоимость заказа;
* стоимость доставки;
* итоговую сумму к оплате.

### 🧪 Тест 1

**Входные данные:**

```text
Стоимость заказа: 4000
Расстояние: 15
Постоянный клиент: нет
```

**Ожидаемый результат:**

```text
Стоимость заказа: 4000 руб.
Доставка: 450 руб.
Итого: 4450 руб.
```

### 🧪 Тест 2

**Входные данные:**

```text
Стоимость заказа: 6000
Расстояние: 8
Постоянный клиент: нет
```

**Ожидаемый результат:**

```text
Стоимость заказа: 6000 руб.
Доставка: 0 руб.
Итого: 6000 руб.
```

# 💳 Задание 2. Банкомат

Необходимо написать программу, которая проверяет возможность снятия денег с банковской карты.

### Входные данные

Пользователь вводит:

* текущий баланс карты;
* сумму снятия;
* PIN-код.

Правильный PIN-код:

```text
1234
```

### Правила

Операция может быть выполнена только при соблюдении всех условий:

1. PIN-код введён правильно.
2. Сумма снятия больше `0`.
3. На счёте достаточно денег.
4. За одну операцию нельзя снять больше **20 000 руб.**
5. Банкомат выдаёт только суммы, кратные **100 руб.**

При успешной операции программа должна вывести выданную сумму и новый баланс.

### 🧪 Тест 1

**Входные данные:**

```text
Баланс: 25000
Сумма: 8000
PIN: 1234
```

**Ожидаемый результат:**

```text
Операция выполнена
Выдано: 8000 руб.
Остаток: 17000 руб.
```

### 🧪 Тест 2

**Входные данные:**

```text
Баланс: 25000
Сумма: 8050
PIN: 1234
```

**Ожидаемый результат:**

```text
Ошибка: сумма должна быть кратна 100
```

### 🧪 Тест 3

**Входные данные:**

```text
Баланс: 10000
Сумма: 15000
PIN: 1234
```

**Ожидаемый результат:**

```text
Ошибка: недостаточно средств
```

# 🎬 Задание 3. Расчёт стоимости билета в кино

Кинотеатр использует автоматическую систему расчёта стоимости билетов.

### Входные данные

Пользователь вводит:

* возраст посетителя;
* час начала сеанса;
* день недели;
* базовую стоимость билета.

Дни недели задаются числами:

```text
1 — понедельник
2 — вторник
3 — среда
4 — четверг
5 — пятница
6 — суббота
7 — воскресенье
```

### Правила расчёта

1. Посетителям младше **12 лет** предоставляется скидка **50%**.
2. Посетителям от **12 до 21 года включительно** предоставляется скидка **20%**.
3. Для сеансов до **12:00** предоставляется дополнительная скидка **10%**.
4. В субботу или воскресенье вечерние сеансы с **18:00** стоят на **20% дороже**.

> Все изменения стоимости применяются последовательно.

### 🧪 Тест 1

**Входные данные:**

```text
Возраст: 20
Время: 15
День недели: 3
Цена: 500
```

**Ожидаемый результат:**

```text
Итоговая стоимость: 400 руб.
```

### 🧪 Тест 2

**Входные данные:**

```text
Возраст: 30
Время: 20
День недели: 6
Цена: 500
```

**Ожидаемый результат:**

```text

```

### 🧪 Тест 3

**Входные данные:**

```text
Возраст: 10
Время: 10
День недели: 2
Цена: 1000
```

**Ожидаемый результат:**

```text

```

# 🚕 Задание 5. Расчёт стоимости такси

Службе такси необходимо рассчитать стоимость поездки с учётом расстояния, времени суток и погодных условий.

* расстояние поездки в километрах;
* час начала поездки (`0–23`);

5. Если расстояние больше **30 км**, предоставляется скидка **15%**.

```text
Расстояние: 10
Час: 14
Дождь: нет
```

```text
Стоимость поездки: 400 руб.
```

```text
Расстояние: 10
```

# 🔐 Задание 6 ⭐. Мини-система авторизации

Необходимо реализовать небольшую систему проверки данных пользователя.

В программе заранее заданы:

```python
correct_login = "admin"
correct_password = "python123"
secret_code = 7777
```

### Входные данные

Пользователь вводит:

* логин;
* пароль;
* секретный код.

### Правила авторизации

1. Если логин неправильный:

```text
Пользователь не найден
```

2. Если логин правильный, но пароль неправильный:

```text
Неверный пароль
```

3. Если логин и пароль правильные, но секретный код неправильный:

```text
Неверный секретный код
```

4. Если все данные правильные:

```text
Добро пожаловать!
```

### 🚨 Аварийный вход

В системе существует специальный режим аварийного входа.

Если:

```text
Логин = admin
Код = 9999
```

вход разрешается **независимо от введённого пароля**.

### 🧪 Тест 1

**Входные данные:**

```text
Логин: admin
Пароль: python123
Код: 7777
```

**Ожидаемый результат:**

```text
Добро пожаловать!
```

### 🧪 Тест 2

**Входные данные:**

```text
Логин: admin
Пароль: hello
Код: 7777
```

**Ожидаемый результат:**

```text
Неверный пароль
```

### 🧪 Тест 3

**Входные данные:**

```text
Логин: user
Пароль: python123
Код: 7777
```

**Ожидаемый результат:**

```text
Пользователь не найден
```

### 🧪 Тест 4

**Входные данные:**

```text
Логин: admin
Пароль: wrong_password
Код: 9999
```

**Ожидаемый результат:**

```text
Добро пожаловать! Аварийный вход.
```

> 💡 Последний тест специально проверяет правильность построения условий. Если проверки расположены в неправильном порядке, программа может отклонить вход из-за неправильного пароля до проверки аварийного кода.
