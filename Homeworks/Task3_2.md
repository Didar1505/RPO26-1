# ⚡ Задание 1. Расчёт стоимости электроэнергии

Необходимо написать программу для расчёта ежемесячной платы за электроэнергию.

### Входные данные

Пользователь вводит:

* предыдущие показания счётчика;
* текущие показания счётчика;
* тип помещения (`1` — квартира, `2` — частный дом);
* наличие льготы (`да` / `нет`).

### Правила

Сначала необходимо определить расход:

```text
Расход = текущие показания - предыдущие показания
```

Для **квартиры**:

* первые 150 кВт⋅ч — **5 руб./кВт⋅ч**;
* всё сверх 150 кВт⋅ч — **7 руб./кВт⋅ч**.

Для **частного дома**:

* первые 250 кВт⋅ч — **4 руб./кВт⋅ч**;
* всё сверх 250 кВт⋅ч — **6 руб./кВт⋅ч**.

Если пользователь имеет льготу, итоговая стоимость уменьшается на **20%**.

Если текущие показания меньше предыдущих, программа должна сообщить об ошибке.

### 🧪 Тест 1

**Входные данные:**

```text
Предыдущие показания: 1200
Текущие показания: 1400
Тип помещения: 1
Льгота: нет
```

**Ожидаемый результат:**

```text
Расход: 200 кВт⋅ч
К оплате: 1100 руб.
```

### 🧪 Тест 2

**Входные данные:**

```text
Предыдущие показания: 500
Текущие показания: 800
Тип помещения: 2
Льгота: да
```

**Ожидаемый результат:**

```text
Расход: 300 кВт⋅ч
К оплате: 1040 руб.
```

### 🧪 Тест 3

```text
Предыдущие показания: 900
Текущие показания: 850
Тип помещения: 1
Льгота: нет
```

**Ожидаемый результат:**

```text
Ошибка: текущие показания не могут быть меньше предыдущих
```

# 🚗 Задание 3. Расчёт штрафа за превышение скорости

Необходимо создать программу для автоматического определения штрафа.

### Входные данные

Пользователь вводит:

* разрешённую скорость;
* фактическую скорость автомобиля;
* находится ли участок в зоне школы (`да` / `нет`);
* является ли нарушение повторным (`да` / `нет`).

### Правила

Сначала вычисляется превышение скорости:

```text
Превышение = фактическая скорость - разрешённая скорость
```

Если превышения нет — штраф отсутствует.

Если превышение составляет:

* от 1 до 20 км/ч — **500 руб.**;
* от 21 до 40 км/ч — **1500 руб.**;
* от 41 до 60 км/ч — **3000 руб.**;
* более 60 км/ч — **5000 руб.**

Дополнительные правила:

* если нарушение произошло в зоне школы — штраф увеличивается на **50%**;
* если нарушение повторное — полученная сумма увеличивается ещё в **2 раза**.

Все изменения применяются последовательно.

### 🧪 Тест 1

```text
Разрешённая скорость: 60
Фактическая скорость: 95
Зона школы: нет
Повторное нарушение: нет
```

**Ожидаемый результат:**

```text
Превышение: 35 км/ч
Штраф: 1500 руб.
```

### 🧪 Тест 2

```text
Разрешённая скорость: 40
Фактическая скорость: 90
Зона школы: да
Повторное нарушение: да
```

**Ожидаемый результат:**

```text
Превышение: 50 км/ч
Штраф: 9000 руб.
```

### 🧪 Тест 3

```text
Разрешённая скорость: 60
Фактическая скорость: 55
Зона школы: нет
Повторное нарушение: нет
```

**Ожидаемый результат:**

```text
Превышения скорости нет
Штраф: 0 руб.
```

# 🎓 Задание 4. Решение о стипендии

Университет автоматически определяет размер стипендии студента.

### Входные данные

Студент вводит:

* средний балл от `0` до `5`;
* количество пропущенных занятий;
* количество академических задолженностей;
* участие в научной деятельности (`да` / `нет`).

### Правила

Если есть хотя бы **одна академическая задолженность**, стипендия не назначается.

Если задолженностей нет:

* средний балл от 3.5 до 3.99 — **2000 руб.**;
* от 4.0 до 4.49 — **3000 руб.**;
* от 4.5 до 5.0 — **5000 руб.**;
* ниже 3.5 — стипендия не назначается.

Дополнительно:

* если пропущено больше 10 занятий — размер стипендии уменьшается на **30%**;
* если студент участвует в научной деятельности **и** его средний балл не ниже 4.5 — дополнительно начисляется **1500 руб.**

Если средний балл меньше `0` или больше `5`, программа должна вывести ошибку.

### 🧪 Тест 1

```text
Средний балл: 4.7
Пропуски: 3
Задолженности: 0
Научная деятельность: да
```

**Ожидаемый результат:**

```text
Основная стипендия: 5000 руб.
Доплата за научную деятельность: 1500 руб.
Итого: 6500 руб.
```

### 🧪 Тест 2

```text
Средний балл: 4.2
Пропуски: 15
Задолженности: 0
Научная деятельность: нет
```

**Ожидаемый результат:**

```text
Стипендия с учётом пропусков: 2100 руб.
```

### 🧪 Тест 3

```text
Средний балл: 4.9
Пропуски: 0
Задолженности: 1
Научная деятельность: да
```

**Ожидаемый результат:**

```text
Стипендия не назначена: имеется академическая задолженность
```

# 📦 Задание 5. Автоматическая камера хранения

Камера хранения принимает посылки только при соблюдении определённых требований.

### Входные данные

Пользователь вводит:

* длину посылки в сантиметрах;
* ширину;
* высоту;
* массу в килограммах;
* является ли содержимое хрупким (`да` / `нет`).

### Правила

Сначала необходимо вычислить объём:

```text
Объём = длина × ширина × высота
```

Посылка не принимается, если:

* хотя бы одна сторона больше **120 см**;
* масса больше **30 кг**;
* объём больше **500 000 см³**.

Если посылка подходит, стоимость хранения рассчитывается следующим образом:

* базовая стоимость — **200 руб.**;
* если масса больше 10 кг — дополнительно **150 руб.**;
* если объём больше 100 000 см³ — дополнительно **200 руб.**;
* если содержимое хрупкое — стоимость увеличивается ещё на **25%**.

Программа должна либо рассчитать стоимость, либо сообщить конкретную причину отказа.

### 🧪 Тест 1

```text
Длина: 50
Ширина: 40
Высота: 30
Масса: 8
Хрупкое: нет
```

**Ожидаемый результат:**

```text
Объём: 60000 см³
Посылка принята
Стоимость хранения: 200 руб.
```

### 🧪 Тест 2

```text
Длина: 100
Ширина: 50
Высота: 30
Масса: 15
Хрупкое: да
```

**Ожидаемый результат:**

```text
Объём: 150000 см³
Посылка принята
Стоимость хранения: 687.5 руб.
```

### 🧪 Тест 3

```text
Длина: 130
Ширина: 20
Высота: 20
Масса: 5
Хрупкое: нет
```

**Ожидаемый результат:**

```text
Посылка не принята: превышен допустимый размер
```

# 🎮 Задание 6 ⭐. Система расчёта результата игры

Игрок завершил игровой уровень. Необходимо определить количество полученных очков и его итоговый ранг.

### Входные данные

Пользователь вводит:

* количество собранных монет;
* время прохождения уровня в секундах;
* количество потерянных жизней;
* найден ли секретный предмет (`да` / `нет`);
* выбранная сложность (`1`, `2` или `3`).

### Расчёт очков

За каждую монету начисляется **100 очков**.

Бонус за скорость:

* менее 60 секунд — `+5000`;
* от 60 до 120 секунд включительно — `+2500`;
* более 120 секунд — бонус отсутствует.

За каждую потерянную жизнь вычитается **1000 очков**.

Если найден секретный предмет:

```text
+3000 очков
```

После этого применяется множитель сложности:

* сложность `1` → `× 1`;
* сложность `2` → `× 1.5`;
* сложность `3` → `× 2`.

Если итоговое количество очков получилось меньше `0`, результат должен быть установлен в `0`.

### Определение ранга

После всех вычислений:

* менее 5000 → ранг `D`;
* 5000–9999 → ранг `C`;
* 10000–19999 → ранг `B`;
* 20000–29999 → ранг `A`;
* 30000 и больше → ранг `S`.

### 🧪 Тест 1

```text
Монеты: 50
Время: 90
Потеряно жизней: 1
Секретный предмет: нет
Сложность: 1
```

Расчёт:

```text
50 × 100 = 5000
Бонус времени = 2500
Штраф = 1000

5000 + 2500 - 1000 = 6500
```

**Ожидаемый результат:**

```text
Итоговые очки: 6500
Ранг: C
```

### 🧪 Тест 2

```text
Монеты: 80
Время: 50
Потеряно жизней: 0
Секретный предмет: да
Сложность: 2
```

Расчёт:

```text
8000 + 5000 + 3000 = 16000
16000 × 1.5 = 24000
```

**Ожидаемый результат:**

```text
Итоговые очки: 24000
Ранг: A
```
