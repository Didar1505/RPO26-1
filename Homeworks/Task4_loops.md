### 🎯 Цель работы

---

## 📌 Что можно использовать

В заданиях разрешается использовать:

- `input()`;
- `print()`;
- `int()` и `float()`;
- арифметические операции;
- `%`;
- `if`, `elif`, `else`;
- `and`, `or`;
- цикл `for`;
- `range(n)` **только с одним аргументом**.

Пример:

```python
n = int(input("Введите количество повторений: "))

for i in range(n):
    print(i)
```

> ⚠️ Напоминание: `range(5)` создаёт последовательность `0, 1, 2, 3, 4`.

# 🏪 Задание 6. Корзина покупок

**Ввод:**

```text

Раунд 1: 150
Раунд 2: 800
Раунд 3: 50
Раунд 4: 1200
Раунд 5: 600
```

Во время работы программа должна вывести:

```text
Раунд 1: Обычный результат

Раунд 3: Плохой результат
Раунд 4: Отличный результат
Раунд 5: Хороший результат
```

