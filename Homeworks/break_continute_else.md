## Задание 1. Поиск первого делителя

Пользователь вводит целое число `n`, большее 1.

Нужно найти **первый делитель числа**, кроме `1`.

Если делитель найден — вывести его и завершить цикл с помощью `break`.

Если цикл закончился без `break`, вывести:

```text
Число простое
```

### Пример

```text
Введите число: 49
Первый делитель: 7
```

```text
Введите число: 13
Число простое
```

### Стартовый код

```python
n = int(input("Введите число: "))

for i in range(2, n):
    # ваш код
```

## Задание 5. Банкомат с повторным вводом

```python

```

Программа постоянно спрашивает сумму снятия.

- если введено `0` — завершить программу через `break`;
- если сумма меньше `0` — пропустить ввод через `continue`;
- если сумма больше баланса — вывести:

```text
Недостаточно средств
```

и продолжить работу;
- если денег хватает — уменьшить баланс и вывести остаток.

### Пример

```text
Баланс: 5000
Сколько снять: -100
Некорректная сумма

Сколько снять: 7000
Недостаточно средств

Сколько снять: 1500
Остаток: 3500

Сколько снять: 0
Работа банкомата завершена
```

### Стартовый код

```python
balance = 5000

while True:
    amount = int(input("Сколько снять: "))

    # ваш код
```
